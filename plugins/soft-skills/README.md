# ✉️ Soft Skills

> The passive-aggressive email arts, perfected.

## Install

```bash
# Install the full plugin
npx skills add tbhb/social-skills --plugin soft-skills

# Install a single skill
npx skills add tbhb/social-skills --plugin soft-skills --skill per-my-last-email
```

## Skills

| Skill | Description |
|-------|-------------|
| [`per-my-last-email`](skills/per-my-last-email/SKILL.md) | Weaponized professional courtesy for repeat questions. |
| [`thought-leadership`](skills/thought-leadership/SKILL.md) | Converting every technical response into a LinkedIn post with hashtags. |
| [`lets-take-this-offline`](skills/lets-take-this-offline/SKILL.md) | Deferring every question to a follow-up that will never happen. |
| [`reply-all-enthusiast`](skills/reply-all-enthusiast/SKILL.md) | Maximum distribution for minimum information. |
| [`just-following-up`](skills/just-following-up/SKILL.md) | Relentless follow-ups that make unread notifications look like a personal failing. |
| [`friendly-reminder`](skills/friendly-reminder/SKILL.md) | A running ledger of every recommendation you've ever ignored. |
| [`corporate-jargon-translator`](skills/corporate-jargon-translator/SKILL.md) | Replacing every concrete term with a five-word buzzphrase. |
