# AGENTS.md

## Project Overview

This repository (`tbhb/social-skills`) is a collection of satirical personality-module "skills" for AI coding agents. Each skill teaches an agent a dysfunctional corporate behavior — passive-aggressive emails, weaponized empathy, process theater, etc. The project is comedic and deliberately absurd; the skills are meant to be funny, not genuinely useful.

Skills are distributed via the `npx skills` CLI and are consumed by agent frameworks that support the SKILL.md format (YAML frontmatter + markdown instructions).

## Skill Anatomy

Every skill lives in `skills/<skill-name>/SKILL.md` and follows this structure:

```markdown
---
name: <skill-name>
description: >-
  A concise description of when and how the agent should activate this skill.
  Written as an instruction to the agent, not a summary for humans.
---

# The "<Display Name>" <Optional Subtitle>

One-line thematic summary.

## System Instruction

A single paragraph giving the agent its persona, behavioral rules,
and constraints. This is the core prompt injection.

## Example Interaction

A **User:** / **Agent:** exchange demonstrating the skill in action.
```

### Conventions

- **`name`** in frontmatter must match the directory name exactly (kebab-case).
- **`description`** is written in second person addressed to the agent ("Use when the user asks…"). It controls when the skill activates via progressive disclosure.
- **System Instruction** is always a single, dense paragraph. No bullet lists, no sub-sections.
- **Example Interaction** uses bold `**User:**` / `**Agent:**` labels. One exchange is sufficient.
- Skills contain **no code, no scripts, no external dependencies**. They are pure prose.

## Skill Categories

Skills are organized into four thematic bundles (defined in `.claude-plugin/marketplace.json`):

| Bundle | Theme |
|--------|-------|
| `48-flaws-of-power` | Apex-predator power moves |
| `weaponized-empathy` | HR-approved emotional intelligence as a weapon |
| `soft-skills` | Passive-aggressive email arts |
| `process-theater` | Governance cosplay for trivial tasks |

## Contributing a New Skill

1. Create `skills/<skill-name>/SKILL.md` following the anatomy above.
2. Add the skill to the appropriate bundle in `.claude-plugin/marketplace.json`.
3. Add a row to the corresponding table in `README.md`.
4. The `.agents/skills/` directory and `skills-lock.json` are managed by the `npx skills` CLI — do not edit them manually.

### Writing Guidelines

- **Commit to the bit.** Every skill should be a fully realized, absurdly specific corporate dysfunction. Half-measures are not funny.
- **Keep the System Instruction to one paragraph.** Density is part of the joke.
- **The Example Interaction should be instantly recognizable.** Pick a scenario anyone who has worked in an office will groan at.
- **Tone is sardonic, not mean.** The target is corporate culture, not individual people.
- **Skill names are kebab-case imperative phrases** (e.g., `say-less-than-necessary`, `never-outshine-the-master`).

## Files You Should Not Edit

- `skills-lock.json` — auto-generated by the skills CLI.
- `.agents/skills/` — managed copies; always edit the canonical `skills/` source.
